# Funding-market calibration philosophy

The initial calibration is intentionally simple and monotonic rather than statistically estimated. Each driver is expressed in natural banking units and has an explicit neutral point, stress scale, spread penalty and capacity effect. This makes later empirical calibration possible without changing the engine architecture.

The current calibration should therefore be treated as a gameplay starting point, not an assertion that a given CET1, LCR, Stage 3 or wholesale-funding change has a universally fixed market-price effect.
