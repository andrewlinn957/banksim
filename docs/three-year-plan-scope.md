# Three-Year Plan scope

The Three-Year Plan is an optional sandbox feature and is disabled by default.

When enabled at the opening, the board supplies one fixed 36-month quantitative mandate. The player manages the bank using the normal department controls and tries to deliver that mandate.

The feature contains only:

- fixed FY1, FY2 and FY3 quantitative targets;
- a monthly view of actual performance versus the current target trajectory;
- formal quarterly reviews;
- Board Confidence derived only from performance versus the plan; and
- a final month-36 scorecard.

It deliberately does **not** contain annual or 12-month mandates, departmental proposals, recommendation cards, target editing, target negotiation, successor plan cycles, or automatic management actions.

The plan has no direct Board Confidence input from cash, LCR, CET1, regulatory status, franchise strength or other non-plan state. Those variables matter only insofar as they change the actual metrics included in the mandate.

Scenario mechanics are separate and are not modified by this feature.
